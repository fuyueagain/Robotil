# 使用说明

赛题：大师赛第一期 · 赛题1 —— 跑得快  
机器人：灵龙 2.0（linglong2）  
动作序列版本：`output/linglong2_ground_clearance_run`（已应用 0.075 m 地面离地补偿）

## 一、提交文件清单

| 文件 | 内容 | 说明 |
| --- | --- | --- |
| `my_motion.pkl` | 机器人动作序列主文件 | 含帧率、根部位姿、30 个关节角、FK 局部关节位置 |
| `live_motion.csv` | 动作序列的逐帧 CSV | 与 pkl 同源，每行一帧，无表头，便于直接读取 |
| `retarget_metadata.json` | 关节契约元数据 | 描述关节顺序、qpos0、限位、四元数约定等 |
| `live_stream_robot.mp4` | MuJoCo 演示视频 | 该动作序列在 MuJoCo 中的演示录像 |

若提交平台要求“动作序列文件”只交一个，请以 `my_motion.pkl` 为主文件；CSV 与元数据作为配套一并提交。

## 二、动作序列格式

### 2.1 my_motion.pkl

Python pickle 字典，关键字段如下：

| 字段 | 形状 | 含义 |
| --- | --- | --- |
| `fps` | float | 播放/采样帧率，本文件为 `30.0` |
| `root_pos` | (661, 3) | 根部位移，单位米（已含离地补偿） |
| `root_rot` | (661, 4) | 根部四元数，顺序 `xyzw` |
| `dof_pos` | (661, 30) | 30 个关节角度，单位弧度 |
| `local_body_pos` | (661, 连杆数, 3) | 本地 FK 计算的各连杆位置，单位米 |
| `link_body_list` | list[str] | 连杆名称列表，顺序与 `local_body_pos` 对应 |

读取示例：

```python
import pickle

with open("my_motion.pkl", "rb") as f:
    motion = pickle.load(f)

fps = motion["fps"]
root_pos = motion["root_pos"]  # (661, 3)
root_rot = motion["root_rot"]  # (661, 4)，xyzw
dof_pos = motion["dof_pos"]    # (661, 30)
```

### 2.2 live_motion.csv

- 共 **661 行（帧）**，无表头、无时间戳；
- 每行 37 列：`根部位移(3) + 根部四元数 xyzw(4) + 30 个关节角(30)`；
- 关节列顺序与 `retarget_metadata.json` 中 `joints` 数组的 `csvIndex` 一致（0 到 29）；
- 位置单位为米，关节角单位为弧度。

读取示例：

```python
import numpy as np

q = np.loadtxt("live_motion.csv", delimiter=",", dtype=np.float32)
root_pos = q[:, :3]      # (661, 3)
root_rot = q[:, 3:7]     # (661, 4)，xyzw
dof_pos = q[:, 7:]       # (661, 30)
```

## 三、关键约定

| 项目 | 约定 |
| --- | --- |
| 机器人 | linglong2（灵龙 2.0） |
| 帧数 | 661 帧 |
| 帧率 | 30 FPS（`my_motion.pkl` 的 `fps=30.0`，演示视频亦按 30 FPS 输出） |
| 位置单位 | 米（m） |
| 角度单位 | 弧度（rad） |
| CSV 与 pkl 的四元数顺序 | `xyzw` |
| MuJoCo qpos 原生四元数顺序 | `wxyz`（读入 MuJoCo 时需要转换，见下文） |
| 自由度数 | 30 个关节 |
| 离地补偿 | 序列根部高度已按灵龙 2.0 脚底几何最低点抬升 0.075 m，避免脚底陷入地面 |

## 四、在 MuJoCo 中回放动作序列

回放时需要灵龙 2.0 的 MuJoCo 模型文件（本项目位于 `assets/LingLong2.0/scene.xml`）。

```python
import pickle
import mujoco

with open("my_motion.pkl", "rb") as f:
    motion = pickle.load(f)

model = mujoco.MjModel.from_xml_path("assets/LingLong2.0/scene.xml")
data = mujoco.MjData(model)

for i in range(len(motion["root_pos"])):
    data.qpos[:3] = motion["root_pos"][i]
    # root_rot 为 xyzw，MuJoCo qpos 需要 wxyz
    data.qpos[3:7] = motion["root_rot"][i][[3, 0, 1, 2]]
    data.qpos[7:] = motion["dof_pos"][i]
    mujoco.mj_forward(model, data)
    # 在该状态下渲染一帧，帧间隔为 1/fps 秒
```

CSV 版本回放方式相同，只需把前两行读取逻辑替换为第二节中的 `np.loadtxt` 示例。

## 五、演示视频

`live_stream_robot.mp4` 为同一动作序列在 MuJoCo 中渲染的演示视频，用于直观核对动作效果（跑步姿态与离地状态）。视频内容与 `my_motion.pkl`/`live_motion.csv` 中的序列对应同一版运行结果。

## 六、生成来源简述

该输出由仓库端到端流程生成：输入人体运动视频 → WHAM 人体姿态估计 → GMR 生成 SMPL-X 人体运动 → 重定向到灵龙 2.0（linglong2）→ 输出 MuJoCo qpos 序列并录制 MuJoCo 演示视频。本版本启用了 `ground_clearance=0.075 m` 的贴地补偿，保证脚底不与地面穿插。
